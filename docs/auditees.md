# Auditees

COA audits 23 local governments in Bukidnon: the province, 2 component cities and 20
municipalities. Names, types and districts follow
[betterbukidnon docs/bukidnon-facts.md](https://github.com/Better-Bukidnon/betterbukidnon/blob/develop/docs/bukidnon-facts.md).

Barangays and water districts are audited separately and are out of scope for now.

## Name variants to expect

- **Impasug-ong** is also written Impasugong, as in COA's file names.
- COA's file names write **Malaybalay City** and **Valencia City**, and the province as
  plain **Bukidnon**.
- **Valencia** and **Quezon** share names with places in other provinces, and **Malitbog**
  and **San Fernando** too. COA's Bukidnon folders keep them apart, but check the province
  on the report cover when a file comes from anywhere else.
